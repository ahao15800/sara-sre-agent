# SARA SRE Agent (Intelligence & Reliability)

SARA SRE Agent 是一个企业级智能化运维代理，旨在通过高度自动化的六阶段架构实现系统的极致可用性与自愈能力。

## 核心架构 (Six-Stage Architecture)

本系统由数据采集层、事件系统、规则引擎、AI 智能判决、信任图谱和 Web 控制台六个核心子系统构成。

---

## 📲 手机一键安装指南 (ReSukiSU)

本模块已针对 **ReSukiSU** (KernelSU 兼容) 进行深度优化。用户无需 PC，直接在手机上即可完成安装。

### 1. 下载安装包
点击仓库根目录下的 [sara_sre_agent_resukisu_v1.0.0.zip](https://github.com/ahao15800/sara-sre-agent/raw/main/sara_sre_agent_resukisu_v1.0.0.zip) 并下载到手机存储。

### 2. 通过 ReSukiSU 管理器安装
1. 打开手机上的 **ReSukiSU 管理器** App。
2. 切换到 **“模块”** 页面。
3. 点击底部的 **“安装模块”** 按钮。
4. 在文件管理器中选择刚才下载的 `sara_sre_agent_resukisu_v1.0.0.zip`。
5. 等待日志输出显示“安装完成”。

### 3. 重启生效
安装完成后，点击页面下方的 **“重启”** 按钮。重启后 SARA SRE Agent 将随系统启动自动运行。
